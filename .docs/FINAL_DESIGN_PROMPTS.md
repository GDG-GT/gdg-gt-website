## Design System Reference

**Colors:**
- Peach: #FFE5B3, #FFC093
- Coral: #FF9A76, #FF8366, #F88377
- Google colors: Blue #4285F4, Red #DB4437, Yellow #F4B400, Green #0F9D58
- Dark text: #2D2D2D
- Gray text: #666666
- White: #FFFFFF

**Typography:**
- Headline: 72-80px desktop, 36-40px mobile
- Subheading: 24px desktop, 16px mobile
- Body: 16-18px desktop, 16px mobile (min)
- Font: Inter, Google Sans, or SF Pro Display style

**Spacing:**
- Desktop: 24-32px gaps, 80px section padding
- Mobile: 16-20px gaps, 48px section padding

**Effects:**
- Border radius: 12-16px cards, 8px buttons
- Shadows: Soft, warm-toned
- Transitions: 200-300ms ease-out
